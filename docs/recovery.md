# Возобновление и устранение неполадок

Агент сохраняет состояние, позицию установщика, хеши и метку загрузки в `%ProgramFiles%\Windows AutoSetup`. Планировщик запускает его при входе того же администратора. Файловая блокировка исключает параллельные процессы AutoSetup. При включённой автоматической перезагрузке агент предварительно записывает состояние на диск.

| Ситуация | Действие |
| --- | --- |
| Ожидается перезагрузка | Перезагрузитесь и войдите тем же пользователем. Агент проверит текущий этап. |
| Пропала сеть или WUA сообщил об ошибке | Восстановите Ethernet, дождитесь завершения обслуживания и нажмите «Повторить остановленный этап». |
| Установщик завершился с ошибкой | Сверьте тихие параметры, код процесса и файл проверки. В запущенном плане хеши и профиль зафиксированы. |
| Питание пропало во время этапа | Проверьте Windows и последний установщик, затем разрешите повтор этапа `Blocked/Interrupted`. |
| USB извлечён | Агент использует уже скопированные установщики. Если копирование прервалось, подключите носитель и повторите запуск. |
| WinPE отказался сопоставить диск | Остановите сценарий. Сверьте исходную VM, ISO и идентификаторы. |
| WinPE остановился после разметки | Восстановите контрольную точку или копию VHDX. Для повторной установки подготовьте новый план из работающей Windows. |
| Нужен откат автозапуска | В журнале выберите «Восстановить записи автозапуска» для того же пользователя. |

Если OOBE не запустил первый этап, откройте установленный `WindowsAutoSetup.exe` и нажмите «Запустить постустановку» в журнале.

Агент убирает задачу `WindowsAutoSetup.Resume` после завершения. Состояние и журнал остаются. После завершения плана можно начать новый, например установить рабочее окружение после постустановки. Предыдущий результат сохраняется рядом с текущим состоянием. Экспорт включает сводку и журнал.
