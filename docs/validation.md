# Отчёт об испытаниях 1.0.0-preview.1

## Выполнено

- Сборка Release .NET и запуск опубликованного self-contained EXE с проверкой встроенной инвентаризации.
- Проверки Windows Forms на хосте. Создаётся окно и отображаются все 11 разделов. Инвентаризация реально читает CIM и доступную информацию о системе. Проверена генерация структуры каталогов во временной папке.
- Хранилище. Чтение записей, новый salt и nonce при перезаписи, отказ на неверном пароле и изменённом теге GCM.
- Сопоставление диска на синтетических данных. Покрыты изменение номера, отсутствие диска, дубли серийного/уникального ID, подмена полей, физическая модель и малый размер.
- Переходы очереди. Перезагрузка, повтор, неожиданное прерывание, предел попыток и порядок Windows Update → программы → FACEIT. На подменённых ответах WUA проверены успешный пустой поиск, ожидание перезапуска, ошибка поиска и потеря сети.
- Защита путей, отказ при повреждённом хеше, атомарная замена состояния и структура файла ответов. План связывает GPT-диск, WinPE, образ системы и профиль установки, а повторная запись утверждённого плана отклоняется.

Команды проверок и упаковки находятся в [документации разработчика](development.md).

Хост отклонил вызов Hyper-V из текущего сеанса за недостатком прав. Новая VM не создана. На этом хосте не выполнялись установка приложений, применение настроек, перезапуски или разметка дисков. Встроенная проверка запрещает очистку физических дисков в этой версии.

## Частичная реализация и отсутствующие функции

- NVIDIA. Доступны инвентаризация GPU и переход к ручной настройке дисплея. Установка Control Panel, автоматические 240 Гц и GPU Scaling отсутствуют.
- Сеть. Доступны системные параметры, ссылка на официальный Zapret и хранение ссылки VLESS. Управление Zapret, Game Filter, IPSet, hosts и импорт Happ выполняются вручную.
- Без автоматизации остались выбор драйверов с сайта производителя по модели, удаление штатных закреплений панели задач, автоматическое переключение загрузочного носителя и отдельный тест Ethernet перед Windows Update.
- Мастер открывает официальные страницы и принимает подтверждение входа. Автоматическое заполнение и проверка сторонней сессии отсутствуют. Мастер открывается из раздела «Аккаунты».
- Ubuntu настраивается при первом входе. Отдельные команды внутри Linux, Paperclip onboarding и перенос баз, агентов и репозиториев выполняются вручную.
- В Windows Update проверяются обновления, доступные стандартному источнику WUA. Необязательные обновления исключены. Специальный поиск необязательного NVIDIA-драйвера отсутствует.

## Перед установкой на основной ПК

1. Прогнать лабораторный сценарий на новой Generation 2 VM, сравнить контрольный файл второго VHDX до и после. Проверить загрузку и загрузку в WinRE.
2. Повторить отказные сценарии со снимками VM, включая отключение питания, отсутствие LAN-драйвера, нехватку места и ошибку перезагрузки. Проверить, что FACEIT остаётся заблокирован до завершения Windows Update.
3. На оборудовании отдельно проверить NVIDIA Control Panel, GPU Scaling, фактические 240 Гц, Secure Boot/TPM/VBS и требования FACEIT AC.
4. Сравнить сетевые стратегии Zapret по нужным сервисам, измерить стабильность после перезагрузки, проверить совместимость FACEIT EU. Проверить импорт VLESS в Happ и пройти реальные входы и 2FA в сторонних сервисах.
5. После успешных тестов пересмотреть ограничение физической установки отдельным изменением и провести испытание на выделенном ПК с расходным диском и проверенной резервной копией.
