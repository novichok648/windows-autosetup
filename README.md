# Windows AutoSetup

**1.0.0-preview.1 · Windows 11 x64**

Автоматическая переустановка и настройка Windows 11.

Портативное приложение на C#/.NET с русским интерфейсом. Оно определяет оборудование, сохраняет профиль, ведёт журнал, управляет локальными установщиками и хранит аккаунты в зашифрованном контейнере.

| Режим | Как запустить | Статус |
| --- | --- | --- |
| Рабочее окружение | Выберите инструменты в одноимённом разделе | WinGet, WSL2, локальные пакеты и отдельная установка инструментов npm. Исполнение внешних установщиков ещё предстоит проверить в VM. |
| Чистая установка Windows 11 Pro | Подготовьте WinPE, утвердите план в тестовой VM и загрузите её с ISO | Экспериментальная цепочка DISM, GPT, WinRE и OOBE только для виртуальных SCSI-дисков Hyper-V. Сквозной тест пока не пройден. |

## Быстрый запуск

1. Распакуйте выпуск `win-x64` и запустите `WindowsAutoSetup.exe`. Установка .NET для запуска не нужна.
2. В «Настройках программы» выберите папку `AutoSetup`. Программа создаст каталоги, если они отсутствуют.
3. Добавьте установщики и сохраните профиль. В рабочем окружении можно выбрать WinGet и npm независимо. Системный агент запрашивает UAC при запуске административной операции.
4. Откройте «Журнал установки» для результата, повтора после ошибки и экспорта диагностики.
