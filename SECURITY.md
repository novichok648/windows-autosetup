# Безопасность Windows AutoSetup

- Очистка диска доступна только в лабораторном сценарии Hyper-V. WinPE требует UEFI, виртуальный SCSI-диск, полный отпечаток, ISO только для чтения и подтверждение при подготовке и исполнении. Используйте отдельный VHDX с резервной копией.
- EXE работает без повышения. Для системных действий приложение через UAC запускает Windows PowerShell. Код агента сверяется по SHA‑256 до исполнения из памяти. Возобновление использует копию в Program Files и интерактивный токен того же администратора.
- Доверяйте исходному ISO, ADK, собранному WinPE и портативному EXE. Хеши подтверждают целостность относительно утверждённого плана. Профиль авторизует запуск выбранных установщиков с их аргументами. Просматривайте профили и берите пакеты у доверенных издателей.
- Контейнер использует AES-256-GCM, случайные соль и nonce и PBKDF2-HMAC-SHA256 с 600 000 итераций. Секреты расшифровываются в память пользовательского процесса. Разблокированное хранилище доступно процессам, способным читать эту память. Резервируйте `Private` отдельно. Потерянный мастер-пароль восстановить невозможно.
- Windows Update, WinGet, npm и страницы входа используют сеть при выбранных операциях. Windows AutoSetup не отправляет журнал, профиль, содержимое хранилища или инвентаризацию. Сторонние приложения работают по своим условиям.
- Сгенерированные носители, журналы, секреты и бинарники исключены из Git. Перед публикацией запустите `scripts/Test-ReleaseContent.ps1`. Скрипт ищет распространённые форматы секретов в индексе.

По вопросам безопасности используйте приватный канал владельца репозитория. Присылайте воспроизведение на синтетических данных.
